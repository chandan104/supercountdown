# Privacy & Data Sovereignty

## User Privacy Principles
1. **Zero Tracking / Zero Analytics**:
   - Super 2027 does not transmit telemetry, browsing behavior, or user logs to third-party ad networks.
2. **Local Data Sovereignty**:
   - All tasks, goals, habits, milestones, and personal notes are stored locally on the device in SQLite through Android Room Database.
3. **AI Request Scoping**:
   - Only the minimal goal and task context necessary to construct the daily action plan is transmitted to the Gemini API endpoint.
4. **Data Portability & Deletion**:
   - Users can export a complete JSON backup of their database at any time from the Settings screen.
   - Deleting tasks, goals, or events permanently removes them from local storage immediately.
